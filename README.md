# Advanced Skills Protocol (ASP) v2.0 🌐

[![ASP v2.0 Compliant](https://img.shields.io/badge/ASP-v2.0_Compliant-blueviolet)](https://github.com/salem221094/universal-skills-protocol)

The **Advanced Skills Protocol (ASP)** is a universal, industry-standard framework for managing and validating AI Agent Skills. It bridges the gap between heuristic AI behavior and deterministic software standards.

## 🚀 Vision
To move AI interactions from **"Best Effort"** to **"Guaranteed Execution."** ASP ensures that AI skills are robust, self-healing, and universally understood by any compliant agent or IDE.

## 📚 Core Documents
- **[Manifesto](MANIFESTO.md)**: The philosophical foundation of deterministic intelligence.
- **[Technical Specification](TECHNICAL_SPEC.md)**: The structural requirements for ASP-compliant skills.
- **[Agent Directive](DIRECTIVE.md)**: Rules for AI agents operating under this protocol.
- **[Community Model](COMMUNITY_MODEL.md)**: The vision for a global, versioned skills registry.
- **[Starter Kit](STARTER_KIT.md)**: Tools to build and audit ASP skills.

## 🛠️ Key Features
- **Structural Predicates**: Mechanical enforcement of skill formatting.
- **Forced Research (Step 0)**: Ensures agents use the latest technology before acting.
- **Self-Healing**: Automated repair scripts to prevent "Skill Drift."
- **Universal Portability**: Works across Claude Code, Cursor, Antigravity, and custom Agents.
