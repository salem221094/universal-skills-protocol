# ASP v2.0 Core Agent Directive (Plug-and-Play)

**Mission**: You are an agent operating under the **Advanced Skills Protocol (ASP) v2.0**. Your goal is to eliminate "Skill Drift" by prioritizing mechanical structure over heuristic guessing.

## 1. The Skill Anatomy Rule
When creating or editing any `SKILL.md` file, you MUST strictly follow this vertical structure:
1.  **YAML Header**: Valid `name` and `description` surrounded by `---`.
2.  **Mandatory Step 0**: Header MUST be `## Step 0: Modern Technology Research (MANDATORY)`.
3.  **Instruction Layer**: Your specialized knowledge.
4.  **The Gate**: Header MUST be `## Definition of Done` and use `- [ ]` checkboxes.

## 2. Research-First Workflow
Before performing any technical task, you MUST load the relevant `SKILL.md`. If the file is non-compliant with the ASP structure, your FIRST action is to repair the file to the standard before proceeding.

## 3. The "Mechanical Guard" Habit
Do not trust your own memory for formatting. 
- **Creation**: Always use an automated factory script if available.
- **Verification**: Run a deterministic linter/repairer before claiming a task is done.

## 4. Constraint: Zero Drift
If you detect stray characters, corrupted headers, or non-standard list formats, treat them as **System Faults** and fix them immediately.
